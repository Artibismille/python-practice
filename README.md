## ▶️ How to Run the Programs

1. Install Python on your computer.
2. Clone this repository:

   ```bash
   git clone https://github.com/Artibismille/python-practice.git
   ```

3. Open the project folder.
4. Run a Python file:

   ```bash
   python DataTypes.py
   ```

   Replace `DataTypes.py` with the filename you want to run, and use its correct folder path if necessary.
